# AlbuminTrak Desktop

نسخة سطح المكتب (ويندوز 64-bit): تعمل بدون إنترنت، والبيانات تُحفظ في `المستندات\AlbuminTrak\data.json`
والنسخ الاحتياطية بالتناوب في `المستندات\AlbuminTrak\Backups\Backup_A.json` و`Backup_B.json`
(نسخة عند فتح البرنامج ونسخة قبل إغلاقه، وكل مرة تُستبدل الأقدم).

```
npm install
npm start          # تشغيل للتجربة
npm run dist       # بناء dist/AlbuminTrak.exe (portable)
```
